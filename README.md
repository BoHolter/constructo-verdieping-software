# Constructo — Verdieping Software Prototype

Static multi-page website prototype for the *Verdieping Software* keuzedeel.

Built with **Visual Studio Code**, **HTML**, **CSS**, and **JavaScript**.

## Preview

Open `Verdieping Software Prototype.html` in a browser, or serve the folder locally:

```bash
# example
npx serve .
```

Or use any static server on port 5500 and visit:

`http://localhost:5500/Verdieping%20Software%20Prototype.html`

## Pages

- Home — intro, hero, services teaser, projects, estimate, about
- `pages/services.html` — services overview
- `pages/projects.html` — project index
- Project detail pages (loft, office, family home, canal townhouse, garden pavilion, rooftop)
- `pages/team.html` — team
- `pages/careers.html` — vacancies
- `pages/about.html` — about
- `pages/contact.html` — contact form

## Structure

```
css/     main.css, project.css, scrollbar.css
js/      theme.js, page.js, scrollbar.js
pages/   inner pages
```
