# Constructo — Verdieping Software Prototype

Static multi-page website prototype for the *Verdieping Software* keuzedeel.

Built with **Visual Studio Code**, **HTML**, **CSS**, and **JavaScript**.

## Live site

https://boholter.github.io/constructo-verdieping-software/

## Preview locally

Open `index.html` or serve the folder:

```bash
npx serve .
```

## Pages

- Home — intro, process, projects, reviews, team, estimate
- `pages/projects.html` — filterable project index (all houses selectable)
- Project detail pages with galleries + before/after lightbox
- Services, process, team, careers, about, FAQ, contact
- Legal: privacy, cookies, terms

## Structure

```
css/     main.css, project.css, scrollbar.css
js/      theme.js, page.js, scrollbar.js, lightbox.js, cookies.js
pages/   inner pages
```
